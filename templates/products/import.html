Expected Excel Columns

Please ensure your Excel file has a header row with the following exact column names:

  • Name (Required)
  • HSN
  • Brand
  • Warranty
  • Unit (e.g. Pcs, Mtrs)
  • Dealer Price (Internal Cost)
  • Customer Price (Selling Price)
  • GST (Percentage e.g. 18)
  • Stock

Existing products with the exact same Name will be updated. New products will be created automatically.
